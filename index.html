Tap Reporting

Internal Services Hub
Authentication Required
All services require a Tap & Barrel Group Azure AD account to log in. If you cannot access a service, please contact the IT department to request login credentials.

Analytics & Insights

Restaurant Data Analysis
A dashboard that integrates and visualizes POS, QSR, GFS, and Reviews data.
Kitchen Insights
A service that automatically retrieves, consolidates, visualizes, and analyzes QSR data.
Review Insights
A service that synchronizes guest reviews from Google and OpenTable and provides various metrics and analysis.
Menu Mapper
A tool to scrape competitors' menu data and compare it with our offerings using a drag-and-drop interface.
TripleSeat Integration
Backend services to retrieve TripleSeat data and integrate with Event Reporting.

Operations & Guest Services

Open Check Report
A tool to review checks not closed by the end of a business day.
Event Reporting
A one-stop location to get receipts from all events across all locations.
Check Reporting
Search checks (by payment, promo, menu item) across all locations; individual check lookup; live open check search.
Discount Card Usage
Automatically retrieve and track Squirrel discount card usage across locations.
Prep Batch
A recipe prep tool that pulls recipes from Fourth to view ingredients, steps, and portion sizes with search, filter and quantity multiplier.
Easy Sign Out
iPad sign in & sign out made easy.
Create POS User
Centralized POS user creation with unique employee number company-wide.

Financial & Cost Control

Daily Cash Reconciliation
A service that automatically synchronizes data from POS and Square to reconcile cash.
OC Automation
Automate COGS retrieval from Optimum Control to calculate gross profit for menu engineering.
EDI
A service to synchronize, parse, and save GFS EDI invoices for analysis and overcharge monitoring.

IT Operations & Administration

Stuck Item Bumper IT Only
Bump off stuck QSR items from QSR screen remotely from a central dashboard.
POS Services Restart IT Only
Restart selected Squirrel or XPO services remotely from a central dashboard.
iPad Reboot IT Only
Reboot POS iPads remotely from a central dashboard.
VM Reboot IT Only
Reboot workstation virtual machine remotely from a central dashboard.
Log Monitoring IT Only
Monitor selected log, detect patterns of concern, and send alert emails.
